Agentic AI from LLM

What is LLM

LLM is like a chile with only brain and no body. It can only process the information and give you the output. It cannot do any action in the real world. It is like a brain without a body.

What is RAG

RAG is the context retrieval system which is used to retrieve the context from the knowledge base and provide it to the LLM for processing. It is like a librarian who retrieves the books from the library and provides it to the reader.

What is an Agent

An agent is an autonomous entity that can perceive its environment and take actions to achieve a specific goal. In the context of AI, agents can be thought of as software entities that can interact with the world and make decisions based on their programming and the information they receive.

What is embedding

Embedding is a technique used to represent text or other data in a continuous vector space. It allows similar items to be located close to each other in the vector space.

What is chunking

Chunking is the process of dividing a large piece of text into smaller, manageable pieces called chunks. This is often done to improve the efficiency of processing and retrieval of information.
We can achive this via python read file and split the text into chunks based on certain criteria, such as sentence boundaries or fixed-length segments.

What is Supervisor

Only routing to different agents and not doing any processing. It is like a manager who assigns tasks to different employees based on their expertise.

What is Vector db and how consine similarity works

A vector database is a type of database that is optimized for storing and searching high-dimensional vector data. Cosine similarity measures the cosine of the angle between two vectors, which indicates how similar they are in terms of direction.

Why we need python to create this LLM agent system

Python is a versatile programming language that is widely used in the field of AI and machine learning. It has a rich ecosystem of libraries and frameworks that make it easy to develop and deploy LLM agent systems.
Some of the popular libraries used in Python for AI and machine learning include TensorFlow, PyTorch, scikit-learn, and spaCy. These libraries provide pre-built functions and models that can be used to build LLM agent systems efficiently.
Functions created by python can be used to create agents that can perform specific tasks, such as data processing, decision making, and action execution. Python's simplicity and readability make it an ideal choice for developing LLM agent systems.
